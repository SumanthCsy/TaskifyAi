## 📖 Project Overview

**TaskifyAi** is an all-in-one AI productivity workspace that empowers users to leverage artificial intelligence for everyday tasks. Whether you need instant answers, comprehensive reports, or code generation - TaskifyAi has got you covered! 🎯

### ✨ Key Features:

🤖 **AI Assistant** - Get intelligent, context-aware responses to your questions with conversation history support. Perfect for research, learning, and problem-solving!

📄 **Report Generator** - Create professional, comprehensive reports with rich formatting and export them as beautiful PDFs. Ideal for assignments, research papers, and business documentation!

💻 **Code Generator** - Generate production-ready code in multiple programming languages with detailed explanations and best practices. Learn while you build!

📊 **Excel & PowerPoint Generation** - Automatically create spreadsheets and presentations from your prompts and reports.

🎨 **AI Image Generation** - Create stunning visuals using advanced AI models (Hugging Face integration).

🔍 **Web Search Integration** - Real-time information retrieval with intelligent web search capabilities.

💾 **Smart Storage** - Save your work, favorite prompts, and maintain conversation history for future reference.

## 🛠️ Tech Stack

### Frontend 🎨
- **React 18** with TypeScript - Modern, type-safe UI development
- **Vite** - Lightning-fast build tool and dev server
- **Tailwind CSS** - Utility-first styling with custom theme support
- **Framer Motion** - Smooth, professional animations
- **Wouter** - Lightweight routing solution
- **React Query** - Powerful data fetching and state management
- **Radix UI** - Accessible, unstyled component primitives
- **Shadcn/ui** - Beautiful, customizable UI components
- **Lucide React** - Crisp, consistent icons

### Backend ⚙️
- **Node.js** with **Express** - Robust server framework
- **TypeScript** - End-to-end type safety
- **Drizzle ORM** - Type-safe database operations
- **PostgreSQL** (Neon Database) - Serverless PostgreSQL
- **Better SQLite3** - Local database support

### AI & ML Integration 🤖
- **OpenRouter API** - Access to Claude 3.5 Sonnet for advanced AI responses
- **Hugging Face Inference** - AI image generation capabilities
- **Custom AI Pipelines** - Optimized prompting and response handling

### Document Generation 📑
- **jsPDF** - PDF generation
- **PptxGenJS** - PowerPoint presentations
- **ExcelJS** - Excel spreadsheet creation
- **React PDF Renderer** - Advanced PDF rendering

### Development Tools 🔧
- **ESBuild** - Fast JavaScript bundling
- **PostCSS** - CSS processing with Autoprefixer
- **Drizzle Kit** - Database migration management
- **Cross-env** - Cross-platform environment variables

### Deployment 🚀
- **Vercel** - Frontend hosting with edge functions
- **Render** - Backend server deployment
- Configured for both **Production** and **Development** environments
